# Paper source

Overleaf-ready LaTeX source for the CVPR course paper. Flat layout, no
subfolders, exactly as exported from Overleaf, so it can be re-zipped and
re-uploaded to Overleaf as-is.

Compile `main.tex` (IEEEtran, conference class) with `pdflatex` (or upload the
whole `paper/` folder to Overleaf).
